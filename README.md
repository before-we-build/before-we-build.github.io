# Before We Build — тест і калькулятор

- `index.html` — інтерактивний типологічний тест. Відповіді обробляються локально у браузері.
- `relations-calculator.html` — калькулятор типових відношень у соціоніці, психософії та темпористиці.

## Банк питань

Сайт намагається завантажити актуальний банк із `before-we-build-research/instruments/pilot-question-bank.md` через GitHub Raw. Банк — це один Markdown-файл зі строгим блоком `~~~question-bank`, що містить валідний JSON.

Для Психософії та Темпористики приймається лише модель `multi-indicator-position-v1`: щонайменше три пілотні індикатори на кожну комірку `аспект × позиція`. Старий однопунктовий remote-банк відхиляється, і сайт використовує вбудований банк v0.5 із 48 пунктами на кожну з цих моделей. Це запобігає поверненню до скорингу, де позиції фактично підмінялися впевненістю, просоціальністю, тривожністю та пасивністю.

Позиційний скоринг нормований у діапазоні `[0, 1]` і може утриматися від типування. Повний тип не показується, якщо хоча б один аспект плоский, близький, неповний або конфліктує з єдиною перестановкою позицій.
