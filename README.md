# Before We Build — тест і калькулятор

- `index.html` — інтерактивний типологічний тест. Відповіді обробляються локально у браузері.
- `research-tests.html` — дослідницький інтерфейс із метаданими, перевірками
  якості та локальним JSON-експортом.
- `relations-calculator.html` — калькулятор типових відношень у соціоніці, психософії та темпористиці.

## Банк питань

Сайт намагається завантажити актуальний банк із `before-we-build-research/instruments/pilot-question-bank.md` через GitHub Raw. Банк — це один Markdown-файл зі строгим блоком `~~~question-bank`, що містить валідний JSON.

Для Психософії та Темпористики приймається лише модель
`multi-indicator-position-contrast-v2`: три індикатори на кожну комірку
`аспект × позиція`, зібрані у 12 matched-vignette квартетів. Віддалений банк
також мусить мати однаковий стимул для всіх чотирьох ролей, повні метадані й
єдиний словник `target / creative / criterion / resource`. Старий або
структурно несумісний банк відхиляється; тоді сайт використовує вбудовані
пілотні банки v0.6 по 48 пунктів.

Скоринг використовує контраст комірки відносно середнього її аспекту, а не
абсолютну згоду. Повний тип не показується, якщо хоча б один аспект плоский,
близький, неповний, суперечить єдиній перестановці позицій або проходження
має критичні ознаки низької якості. Соціонічний модуль до калібрування
повертає лише exploratory-профіль восьми шкал без TIM-коду.

Інструменти залишаються невалідованим пілотом. План cognitive interviews,
expert Q-sort, ESEM/MTMM, DIF, ретесту й holdout-перевірки описаний у
`docs/psychometric-validation-plan.md`.
